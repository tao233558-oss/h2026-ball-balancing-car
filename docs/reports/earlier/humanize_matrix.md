# 设计报告人工化复核矩阵

| 写作单元 | 采用的论证结构 | 证据边界 | 语言处理 |
|---|---|---|---|
| 摘要 | 设计对象→方法→阶段状态 | 只陈述已实现架构与已完成阶段检查 | 长短句混排，不写“全面实现”等虚假完成语 |
| 第1页 系统方案 | 问题拆分→方案比较→总体结构 | 方案来自当前F407、K230与齿轮齿条工程 | 比较项直接说明取舍原因，避免套话式总结 |
| 第2页 循迹控制 | 现场误判现象→成因→算法修正 | 使用连续黑区与邻近段选择的真实调试记录 | 保留工程判断语气，不把普通PI包装成创新算法 |
| 第3页 滚球控制 | 动力学推导→车体扰动→机构与控制 | 参数来自现有ball_balance与stepper代码 | 公式后紧接物理含义，句长有明显变化 |
| 第4页 硬件 | 资源需求→接口分配→保护 | 引脚和定时器来自当前STM32F407工程 | 以接口事实为主，减少泛化形容词 |
| 第5页 软件通信 | 调度冲突→分层时序→异常退化 | 10 ms、20 kHz、200 ms等来自现有程序 | 使用因果链，避免每段同构 |
| 第6页 分题策略 | 公共底层→六题差异→标定整定 | 未把未实测参数写成达标结果 | 任务表承担重复信息，正文解释关键选择 |
| 第7页 测试 | 测试原则→已有记录→待填数据 | 已验证与待联合实测明确分栏 | 不编造圈速和误差；给出可执行填表方式 |
| 第8页 误差结论 | 误差模型→抑制措施→阶段结论 | 结论限定在现有证据范围 | 保留尚未解决问题，不写空泛展望 |

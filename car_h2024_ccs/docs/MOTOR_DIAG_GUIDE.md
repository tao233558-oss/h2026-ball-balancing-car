# 低PWM单轮电机安全测试

这个模式会产生真实电机动作，只允许车轮悬空时使用。任何落地测试都必须等单轮方向、
编码器符号和急停全部确认后再进行。

## 电机接线

| 功能 | 天猛星引脚 |
|---|---|
| 左轮PWM | PA29 / TIMG6_CCP0 |
| 左轮方向 | PB24、PB20 |
| 右轮PWM | PA30 / TIMG6_CCP1 |
| 右轮方向 | PB19、PB18 |
| 电机驱动STBY | PB16 |

编码器仍使用：左轮PA12/PA13，右轮PA24/PA15。

## 固件安全规则

- 固定测试PWM为600，满量程为9999。
- 上电后必须检测到SW2连续释放500ms，OLED的`ARM`才会从N变成Y。
- SW2按下稳定30ms后才启动；松开SW2不等待消抖，在同一个10ms循环停止。
- 每次只允许左轮或右轮中的一只获得PWM。
- 方向和PWM在PB16/STBY为低时设置，最后才拉高STBY。
- SW4任何一次低电平都会锁存急停；松开SW4也不会恢复，必须复位或重新上电。
- 非运行状态先拉低PB16/STBY，再把左右PWM清零。

## 按键

| 按键 | 引脚 | 功能 |
|---|---|---|
| SW1 | PA27 | 在左轮和右轮之间切换，只能停止时操作 |
| SW2 | PA17 | 按住运行，松开停止 |
| SW3 | PB23 | 切换前进/后退方向，只能停止时操作 |
| SW4 | PB27 | 锁存急停，复位才能解除 |

## 当前默认状态

源码默认不会进入电机测试：

```c
#define APP_PROFILE_E2025    1
#define APP_PROFILE_MOTOR_DIAG 0
```

单独编译好的诊断固件：

`output/firmware/car_final_ccs_motor_diag.out`

## OLED显示

- 第一行：安全停止、按住运行或急停状态。
- 第二行：`SEL`为当前选择的左轮L/右轮R，`DIR`为前进F/后退B。
- 第三行：固定PWM以及是否完成解锁。
- 第四行：左右编码器最近约100ms的方向修正增量。

串口输出示例：

```text
MOTOR SEL=L DIR=F PWM=600 ARM=1 RUN=1 ESTOP=0 dL=+8 dR=+0
```

## 硬件回来后的操作顺序

1. 断开电机主电源，把车轮悬空并固定车身。
2. 接好XDS110、Type-C和电机/编码器信号线。
3. 烧录`car_final_ccs_motor_diag.out`。
4. 先不给电机主电源，确认OLED显示安全状态，并测试SW4会进入永久急停。
5. 复位解除急停，确认SW2已经释放且`ARM:Y`。
6. 接通电机主电源，默认选择左轮、前进方向。
7. 短按住SW2约0.5秒，松开后必须立即停转；右轮不应转动。
8. 查看左编码器增量：前进应为正，后退应为负。
9. 用SW1选择右轮，重复测试。
10. 运行时按SW4，电机必须立即停止且不能自行恢复。

若PWM 600完全不转，先检查电机电源、共地、PB16/STBY和驱动接线。不要直接大幅提高PWM。
确认接线正确后，才把`user/motor_diag.c`顶部的`MOTOR_DIAG_PWM`按100逐级增加。

## 通过标准

- 上电或复位时不会自动转动。
- SW2松开立即停止。
- SW4急停锁存有效。
- 只转被选择的一只轮子。
- 前进编码器为正、后退为负。
- 另一只轮的编码器基本为0。

全部通过后，下一阶段才是双轮悬空同速测试。

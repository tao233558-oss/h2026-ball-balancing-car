## 2. 电源与共地总表

| 电源节点 | 接到哪里 | 要求/备注 |
|---|---|---|
| 电池正极 | 保险丝→总开关→动力电源分配 | 保险丝尽量靠近电池正极；先断电再接线 |
| 电池负极 | 系统公共 GND 汇流点 | STM32、TB6612、DCC-100、K230、巡线模块、OLED、编码器必须共地 |
| TB6612 `VM` | 与直流电机额定电压匹配的动力电源 | 不接 STM32 的 3.3 V；电机电源与逻辑电源分开走线 |
| TB6612 `VCC` | STM32 `3V3` | 控制逻辑为 3.3 V |
| DCC-100 绿色端子 `+`/`-` | `+` 接 11～26 V，`-` 接公共 GND | 严格按板上正负丝印接；不能反接 |
| K230 电源 | 独立稳定 5 V 降压或合规 USB-C 5 V | 不建议由 STM32 板载小电流 5 V 口带载；与 STM32 共地 |
| STM32F407 开发板电源 | 按开发板标注接 5 V/VIN 或 USB 供电 | 不要把未知电池电压直接接 5 V/3V3 引脚 |
| 四路巡线模块电源 | 推荐 `VCC/5V` 端接 STM32 `3V3`，`GND` 接公共 GND | 手册允许 3.3～5 V；直接接 F407 GPIO 时优先 3.3 V。若用 5 V供电，先确认四路输出电压不会伤害 MCU |
| OLED 电源 | `VCC` 接 `3V3`，`GND` 接公共 GND | 避免 OLED 模块把 SCL/SDA 上拉到 5 V |
| 编码器电源 | 按编码器铭牌接 3.3 V或5 V，GND 共地 | A/B 输出进入 F407 前必须是 0～3.3 V安全逻辑；5 V推挽输出需降压/电平转换 |

推荐将电机/DCC 动力回流与数字地在电池负端单点汇接，K230、巡线和 OLED 的供电线远离电机线与步进线。

## 3. Hiwonder 四路数字巡线模块（已启用）

模块正面朝上、探头/电位器在上方时，手册图中 6 针接口从左到右为：`5V、GND、S1、S2、S3、S4`。安装到车上后，传感器从车体左到右为 `S1、S2、S3、S4`。

| 模块端 | STM32F407 端 | GPIO 模式 | 当前程序含义 |
|---|---|---|---|
| `5V/VCC` | `3V3`（推荐） | — | 模块供电；手册允许 3.3～5 V |
| `GND` | `GND` | — | 公共地 |
| `S1`（最左） | `PB1` | 上拉数字输入 | 黑线=1，白底=0 |
| `S2`（左内） | `PB0` | 上拉数字输入 | 黑线=1，白底=0 |
| `S3`（右内） | `PC5` | 上拉数字输入 | 黑线=1，白底=0 |
| `S4`（最右） | `PC4` | 上拉数字输入 | 黑线=1，白底=0 |

安装高度按手册推荐约 8 mm 起调；四个电位器逐路调节。若左右方向反了，应先检查模块物理朝向和 S1～S4 插线，不能直接在程序里随意交换。

## 4. TB6612 双路直流电机驱动（已启用）

| TB6612 端 | STM32F407/外设端 | 功能 |
|---|---|---|
| `PWMA` | `PE13 / TIM1_CH3` | 左电机 PWM |
| `AIN1` | `PD0` | 左电机方向 1 |
| `AIN2` | `PD1` | 左电机方向 2 |
| `AO1/A01`、`AO2/A02` | 左直流电机两端 | 左轮动力输出 |
| `PWMB` | `PE14 / TIM1_CH4` | 右电机 PWM |
| `BIN1` | `PD2` | 右电机方向 1 |
| `BIN2` | `PD3` | 右电机方向 2 |
| `BO1/B01`、`BO2/B02` | 右直流电机两端 | 右轮动力输出 |
| `STBY` | `PD4` | 高电平使能，低电平待机 |
| `VCC` | `3V3` | 逻辑电源 |
| `VM` | 电机动力电源 | 电压按电机和驱动板额定值确定 |
| `GND` | 公共 `GND` | 必须与 STM32 共地 |

若某一侧前进方向相反，优先交换该侧电机的两根输出线；不要同时交换电机线和编码器 A/B，否则排错会混乱。

|---|---|---|
| 左编码器 `A` | `PB4` | `TIM3_CH1` |

## 6. OLED 显示屏（已启用）

| OLED 端 | STM32F407 端 | 说明 |
|---|---|---|
| `VCC` | `3V3` | 推荐 3.3 V供电 |
| `GND` | `GND` | 公共地 |
| `SCL/CLK` | `PB10` | 软件 I²C 时钟 |

## 7. 四个按键（已启用）

每个按键一端接 GPIO，另一端接公共 GND。程序使用 MCU 内部上拉，按下为低电平，不需要再接外部上拉电阻。

| 按键 | STM32F407 端 | 当前功能 |
|---|---|---|
| `SW1` | `PE7` | 停车状态下降低速度档位 |
| `SW2` | `PE8` | 停车状态下提高速度档位 |
| `SW3` | `PE9` | 启动/停止循迹 |
| `SW4` | `PE10` | 按住时紧急停车；启动时必须未按下 |

## 8. DCC-100 V3 第一路步进驱动（已接但休眠）

| DCC-100 第一路端 | STM32F407/外设端 | 说明 |
|---|---|---|
| `PWM/STEP` | `PA6` | 每个脉冲走一个微步 |
| `DIR` | `PA7` | 方向控制 |
| `SLP` | `PA5` | 高电平工作，低电平休眠 |
| `RST` | `PA4` | 高电平工作 |
| `DCY` | 不接，悬空 | 按手册自动确定电流衰减模式；当前驱动明确不使用 |
| 控制侧 `GND` | STM32 `GND` | 3.3 V逻辑的参考地 |
| 绿色供电端子 `+` | 11～26 V正极 | 按 DCC-100 手册供电 |
| 绿色供电端子 `-` | 电源负极/公共 GND | 与 STM32 共地 |
| 第一路电机口 `A+、A-` | 步进电机同一相线圈 | 万用表测通断确认线圈对 |
| 第一路电机口 `B+、B-` | 步进电机另一相线圈 | 不要把不同线圈各取一根组成一对 |
| 第二路全部接口 | 暂不接 | 当前工程只定义第一路 |

当前 `main.c` 在初始化后立即执行急停，因此 `SLP`、`RST` 保持低电平，步进电机不会动作。这不是接线故障。

## 9. K230 视觉串口（预留未启用）

| K230 端 | STM32F407 端 | 说明 |
|---|---|---|
| 40 针物理第 11 脚 / `GPIO5 / UART2_TXD` | `PA3 / USART2_RX` | K230→STM32 单向 3.3 V TTL |
| 40 针物理第 9 脚 / `GND` | STM32 `GND` | 必须共地 |

## 13. 上电前检查顺序

1. 断电状态下用万用表确认电池正负极、DCC 绿色端子正负极和各电源输出电压。
2. 先只给 STM32、OLED、按键和四路巡线供电，确认 OLED 与 S1～S4 状态正确。
3. 再接 TB6612 逻辑电源，不接电机动力，确认 `STBY`、PWM 和方向脚无短路。
4. 架空车轮后接电机动力，低速检查左右轮方向和编码器计数方向。
5. 最后接 DCC-100 动力和步进电机；先保持休眠，再单独使用步进测试程序验证方向与限位。
6. K230 使用独立 5 V供电，最后接 TX 与 GND；严禁带电插拔错位排针。

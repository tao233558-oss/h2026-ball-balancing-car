# 钢球数据集标注说明

- 类别：`steel_ball`
- 图片：52 张，均为 1920×1080 JPEG
- 标注框：756 个矩形框
- X-AnyLabeling 标注：与图片同名的 `.json` 文件，放在图片旁边
- YOLO 标注：`labels_yolo` 文件夹中的同名 `.txt` 文件
- 类别表：`classes.txt`
- 汇总表：`annotation_summary.csv`

## 标注规则

1. 主图中边界可辨认的独立钢球按矩形框标注。
2. 网页按钮、导航图标、文字、反光斑不标注。
3. 被画面边缘裁切但主体仍可辨认的钢球保留标注，框裁切到图像边界。
4. 密集堆叠、强遮挡或严重模糊的图片标记为 `checked: false`，对应框的
   `difficult` 为 `true`，应在训练前用 X-AnyLabeling 做最后复核。

## 在 X-AnyLabeling 中打开

启动 `X-AnyLabeling-v4.0.0-beta.12-CPU.exe`，选择“打开目录”，打开本
`steel_ball_dataset` 文件夹。程序会读取图片旁边同名的 JSON 标注。

橙色复核总览位于项目根目录的 `steel_ball_annotation_review` 文件夹。

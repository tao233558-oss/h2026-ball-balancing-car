# E2025 云台与激光安全适配层

## 当前结论

E2025 的瞄准命令已经接入纯软件安全适配层，但默认关闭，而且适配层没有任何 GPIO 操作：

```c
#define E2025_OFFLINE_SIMULATION 1
#define E2025_ENABLE_AIM_ADAPTER 0
```

即使临时把 `E2025_ENABLE_AIM_ADAPTER` 改为 1，也只会计算虚拟的水平/垂直步数和激光许可，不会在真实引脚上输出 STEP、DIR 或激光电平。

原来 E2025 初始化中的 `stepper_init()` 调用已经取消。PA14、PA26 在正式引脚确认前不会被主程序当作云台 GPIO 初始化。

## 为什么需要视觉看门狗

K230 通信层会保存最后一帧正确数据。如果串口断线，缓存中的靶点和光斑标志仍可能保持有效。只检查 `target_valid` 会导致云台继续使用旧坐标，逻辑激光请求也可能保持开启。

适配层现在要求：

- 当前任务允许瞄准；
- 已经在本次任务中收到至少一帧新数据；
- 距离最近新帧不超过 100 ms；
- 靶点与激光光斑标志同时有效；
- 没有 SW4 急停锁存；
- 没有向外撞到软件限位。

任一条件不满足时，水平步数、垂直步数和激光许可全部立即清零。

## 虚拟步进转换

状态机输出的 `pan_command`、`tilt_command` 范围为 -1000～1000。适配层使用余数累加器转换为步数：

- 每累计 250 个命令单位产生 1 个虚拟步；
- 每个 10 ms 周期每轴最多输出 4 步；
- 命令方向反转时丢弃旧方向余数，避免反向迟滞；
- 命令为 0、视觉失效或任务停止时清空余数。

这些比例只是软件占位值。电机细分、减速比、云台角度和相机像素误差尚未标定，不能直接当作真实角度参数。

## 软件限位

水平和垂直位置从芯片上电时的虚拟原点开始累计，当前限制为每轴 ±2000 步：

- 达到边界后禁止继续向外运动；
- 允许立即反向退回；
- 触发边界阻挡的周期关闭激光许可。

这只是防止软件无限连续输出的第二层保护，不能代替机械限位开关。因为没有回零传感器，上电原点也不等于真实机械中点。

## SW4 急停

瞄准任务运行时按下 SW4/PB27：

- 当前 10 ms 周期停止云台虚拟输出；
- 激光许可立即清零；
- 急停故障永久锁存，必须复位芯片才能清除。

在菜单中按 SW4 不会触发适配层急停，因为任务尚未运行。

## 离线回放

```powershell
python offline_tools\e2025_aim_adapter_sim.py
```

结果位于 `output/e2025_aim_adapter_sim/summary.json`。回放验证旧缓存帧拒绝、视觉超时、步数限幅、微小命令累加、双有效互锁、软限位返回和急停锁存。

## 硬件回来后的接入顺序

1. 最终确定水平轴 STEP/DIR、垂直轴 STEP/DIR、两轴限位输入和激光使能引脚。
2. 确认 DCC-100 输入电平、STEP 最短高低电平、DIR 建立时间和公共地。
3. 确认激光驱动有效电平，确保芯片复位和断线时默认关闭。
4. 单独建立低速云台诊断模式，先不接激光，逐轴验证方向和限位开关。
5. 完成机械回零，再用真实步数替换当前 ±2000 的上电相对软限位。
6. 标定像素误差到步数/角度的比例，并逐渐提高最大步频。
7. 最后在独立电源开关、护目措施和安全挡板到位后测试激光互锁。

当前阶段只验证软件边界和编译，不代表云台或激光已经通过实物测试。

瞄准适配器之后的非阻塞脉冲、安全限位和激光互锁执行层已经完成，见 `docs/E2025_AIM_EXECUTOR_GUIDE.md`。由于最终接线表仍缺第二轴、物理限位和激光使能定义，该执行层目前故意不绑定 GPIO，也不接入主程序。

# K230 当前与历史协议说明

本目录为了“完整交接”保留了 MSPM0 双板阶段、二进制 V2 阶段和当前 STM32F407 阶段的代码，因此不同 README 中的接线与协议并不完全相同。

当前整车实际使用的是：

```text
K230 40Pin 第11脚 GPIO5/TX
    -> STM32F407 PA3 / USART2_RX
9600 baud, 8N1, 3.3V TTL, 共地
ASCII: [x,y]\r\n
```

当前 STM32 接收入口：

```text
STM32F407完整Keil工程/bsp/vision_uart/bsp_vision_uart.c
STM32F407完整Keil工程/protocol/vision_ascii/vision_ascii_parser.c
```

以下内容只作为历史参考，不得直接套到当前 STM32 接线：

- `h2026_uart_protocol`：早期 MSPM0 A/B 双板二进制协议。
- `h2026_uart_protocol_v2`：早期 MSPM0-B 串口 V2 测试。
- `k230_e2025`：2025 E 题靶面/激光视觉工程，不是当前钢球主程序。

当前 TF 卡实际运行的最新 `main.py`、模型 `.kmodel` 和配置如果与本目录备份不同，应以 TF 卡为准，并先完整复制一份再修改。不要为“统一目录”删除历史文件。

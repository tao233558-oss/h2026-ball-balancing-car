## 4. 已确定的K230串口

使用UART2单向发送：

| 庐山派标准版 | 连接 | MSPM0-B |
|---|---|---|
| GH1.25串口2座 T脚 / GPIO11 / UART2_TXD | -> | 任意一个3.3V UART RX |
| GH1.25串口2座 G脚 / GND | - | GND |
| GH1.25串口2座 R脚 / GPIO12 / UART2_RXD | 首版不接 | - |
| GH1.25串口2座 V脚 / 5V | 严禁连接 | - |

参数：

```text
115200 baud
8 data bits
no parity
1 stop bit
3.3V TTL
no flow control
```

B端具体UART实例和引脚由单片机队友在SysConfig中决定。严禁接5V串口电平；K230、A、B最终必须共地。

选择UART2的原因：

1. 官方文档明确推荐GH1.25串口2座；
2. 带锁插头比杜邦线更适合运动小车；
3. UART4的多个候选脚与摄像头I²C或音频复用；
4. UART3在系统占用和外接接口方面更复杂；
5. 当前发布器已经按UART2编写。

若没有GH1.25配套线，可临时使用同一UART2外设的40Pin物理11脚
`GPIO5/UART2_TXD`和物理9脚GND，同时把发布器 `tx_gpio` 改为5。两套引脚只能二选一。

官方依据：

- [庐山派UART排针表](https://wiki.lckfb.com/zh-hans/lushan-pi-k230/basic/uart.html)
- [CanMV UART API](https://www.kendryte.com/k230_canmv/en/main/api/machine/k230_canmv_uart_api_manual.html)
- [CanMV FPIOA教程](https://www.kendryte.com/k230_canmv/en/main/example/peripheral/fpioa.html)

## 5. K230到B的冻结数据包

运行期只要求B接收 `0x10 VISION_SAMPLE`：

```text
x_mm
confidence
flags
frame_id
sample_age_ms
inference_ms
```

K230只提供测量，不发送电机方向、步数、PID输出或摆杆角度。B根据 `VALID` 和数据年龄决定是否采用。
完整帧头、CRC、大小端和测试向量见协议文档。

## 6. 下一步联调顺序

1. 单片机队友在B上选择一个3.3V UART RX，并确认具体接线端子；
2. 连接GH1.25串口2座的T脚到B的RX，G脚到B的GND，V脚悬空；
3. K230先不开摄像头，循环发送 `-100/-50/0/+50/+100 mm`；
4. B只打印接收到的位置、序号、CRC统计，暂不驱动步进电机；
5. 连续运行5分钟无错包后，合入YOLO11球位发送；
6. 固定相机后采集 `-100/0/+100 mm` 三个标定像素；
7. 验证最大摆杆倾角下 `-50/0/+50 mm` 误差；
8. 关闭RTSP测试UART，再打开RTSP重复测试；
9. 记录最小视觉帧率、最大串口包间隔和最大 `sample_age_ms`；
10. 最后才让B使用视觉值闭环驱动42步进电机。

## 8. 交流时不要混淆

- 正式方案的GPIO11是芯片GPIO号，对应GH1.25串口2座T脚，不是40Pin物理11脚；
- 40Pin物理11脚实际是GPIO5，只作为无GH配套线时的备用；
- 球槽机械挡片不是电气限位开关；
- `frame_id`代表新推理，`sequence`代表新串口包；
- `VALID=0`的合法包说明串口在线，但当前球位不可用于控制；
- 图传是否连接不应改变UART数据格式；
- 单片机队友可以调整A-B协议，但不要改变已冻结的K230 `VISION_SAMPLE`而不同步通知视觉端。

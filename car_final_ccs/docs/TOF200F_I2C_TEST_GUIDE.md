# TOF200F I²C 测距测试指南

## 当前完成状态

- 正式接线：`PB0 -> SCL`、`PB1 -> SDA`、`3V3 -> VIN`、`GND -> GND`。
- OLED 与 TOF200F 共用 PB0/PB1；两条线均采用开漏方式，只拉低或释放。
- 已接入客服包中的 ST VL53L0X API，测试程序会检查芯片标识 `0xEEAA`、完成初始化与校准，然后每 200 ms 单次测距。
- CCS/TI-Clang 已编译通过；由于当前没有硬件，真实应答、距离准确度和总线波形仍为 `NOT RUN`。

## 第一次使用前：把模块切到 I²C 模式

TOF200F 出厂通常工作在 UART 模式。这时模块内部 MCU 没有把 SDA/SCL 直接交给 VL53L0X，所以天猛星访问 7 位地址 `0x29` 会无应答。

先用 USB-TTL 临时连接 TOF200F 的 5/6 脚，串口设置为 `115200, 8, N, 1`，发送下列十六进制字节：

```text
01 06 00 09 00 01 98 08
```

发送时必须选择“HEX 发送”，不能当作普通文本发送。完成后给 TOF200F 重新上电，再进行 I²C 测试。最终 PCB 上的 5/6 脚只作为配置/恢复测试点，不接 PB4/PB5。

## 测试固件

专用固件：

```text
output/firmware/car_final_ccs_tof200f_i2c_test.out
```

下载器仍为 XDS110。测试固件的输出：

- CH340 串口：`115200, 8, N, 1`。
- OLED：显示初始化状态和距离。
- 板载 LED：`range_status=0` 时点亮；初始化或测量失败时熄灭/闪烁。

正常串口输出示例：

```text
TOF200F I2C test start
VL53L0X init OK, model id=0xEEAA
TOF distance: 356 mm, range_status=0
```

## 错误码

| stage | 含义 | 优先检查 |
|---:|---|---|
| -1 | 地址 `0x29` 无应答 | 模块是否已切 I²C；PB0/PB1 是否接反；是否共地；供电是否正常 |
| -2 | 有应答但芯片标识不是 `0xEEAA` | 总线串扰、地址冲突、接错模块 |
| -3 | ST DataInit 失败 | 上拉、波形、供电、电平 |
| -4 | ST StaticInit 失败 | 同上 |
| -5 | 参考校准失败 | 遮挡、供电和 I²C 稳定性 |
| -6 | SPAD 管理失败 | 传感器状态或总线错误 |
| -7/-8 | 测量模式或参数配置失败 | 初始化流程未完成、通信不稳定 |
| -9 | 单次测距失败 | 查看同时输出的 ST API 错误码 |

`range_status` 不是驱动初始化错误。它为 0 时测量有效；非 0 通常表示目标过近、过远、反射太弱或环境光干扰，需要结合实际摆放复测。

## 上电测试顺序

1. 小车先不接电机主电源，只给控制板和 TOF200F 供电。
2. 用万用表确认 TOF200F 的 VIN、GND 和 3.3 V 电平没有异常。
3. 烧录 TOF 专用固件，打开 CH340 串口。
4. 若显示 `stage=-1`，先处理模块模式和接线，不要继续调软件参数。
5. 初始化成功后，分别在 100、300、500、1000 mm 放置漫反射目标，记录显示值。
6. 最后再用示波器检查 PB0/PB1：空闲应为高电平，主机与从机都只能主动拉低。

## 恢复正常工程

仓库默认已恢复为：

```c
#define APP_PROFILE_E2025      1
#define APP_PROFILE_TOF_TEST   0
#define E2025_OFFLINE_SIMULATION 1
```

需要自行重新编译 TOF 档时，只交换前两个宏，且保证所有 `APP_PROFILE_*` 中只有一个为 1。

# 双轮悬空同速安全测试

这个阶段只验证两只驱动轮在相同低 PWM 下能否同时启动、方向是否一致，以及左右编码器反馈是否基本一致。它会产生真实电机动作，必须先完成单轮测试，并把两只车轮悬空、固定车身后才能使用。

当前没有硬件，因此这里只完成代码、离线安全检查和 CCS 编译；文中的阈值还不是实车标定结果。

## 接线复核

| 功能 | 天猛星引脚 |
|---|---|
| 左轮 PWM | PA29 / TIMG6_CCP0 |
| 左轮方向 | PB24、PB20 |
| 右轮 PWM | PA30 / TIMG6_CCP1 |
| 右轮方向 | PB19、PB18 |
| 电机驱动 STBY | PB16 |
| 左编码器 A/B | PA12、PA13 |
| 右编码器 A/B | PA24、PA15 |
| SW2（按住运行） | PA17，低电平按下 |
| SW3（切换方向） | PB23，低电平按下 |
| SW4（锁存急停） | PB27，低电平按下 |

SW1/PA27 在这个测试中不使用。

## 操作逻辑

- 固定测试 PWM 为 600，左右轮获得相同命令。
- 上电后必须让 SW2 连续释放 500 ms，OLED 右侧出现 `A` 后才允许启动。
- 按住 SW2 运行，松开后不等待消抖，在同一个 10 ms 主循环内停止。
- 停止时按 SW3 切换前进 `F` / 后退 `B`；运行中按 SW3 不会改变方向。
- SW4 任意一次检测到低电平都会立即锁存急停，并拉低 PB16/STBY；只能复位或重新上电解除。
- 任何编码器故障都会锁存，程序不会自行重新启动。
- 每次启动时先保持 PB16/STBY 为低，设置两个方向和 PWM 后才拉高 STBY。

## 当前保护阈值

编码器每 100 ms 统计一次。启动后的前 500 ms 是机械启动宽限期，此后按下表判断：

| 故障 | 当前占位判据 | 锁存时间 |
|---|---|---:|
| `NO FEEDBACK` | 左右计数绝对值都小于 2 | 连续 10 次，约 1.0 s |
| `LEFT MISSING` | 左侧小于 2、右侧不小于 2 | 连续 3 次，约 0.3 s |
| `RIGHT MISSING` | 右侧小于 2、左侧不小于 2 | 连续 3 次，约 0.3 s |
| `LEFT DIR` / `RIGHT DIR` | 计数不小于 2，但符号与命令方向相反 | 连续 3 次，约 0.3 s |
| `SPEED DIFF` | 较大计数不小于 4，左右差值超过较大值的 50% | 连续 5 次，约 0.5 s |

这些阈值故意偏保守。实车回来后必须记录正常左右轮的 100 ms 计数，再决定是否调整；速度差故障并不等同于精确闭环控制。

## OLED 和串口

OLED 显示：

- 第1行：安全停止、运行或锁存故障。
- 第2行：方向和固定 PWM。
- 第3行：左右编码器最近 100 ms 增量；最右侧 `A` 表示已解锁。
- 第4行：故障名称。

CH340 串口仍使用 115200、8N1，示例：

```text
DUAL DIR=F PWM=600 ARM=1 RUN=1 FAULT=NONE dL=+12 dR=+11
```

## 硬件回来后的测试顺序

1. 必须先分别通过单轮测试，确认两轮前进计数均为正、后退均为负，SW4 能锁存急停。
2. 断开电机主电源，把两只车轮悬空并固定车身，确认轮胎、线束和工具不会碰到车轮。
3. 烧录 `output/firmware/car_final_ccs_dual_motor_diag.out`，先不给电机主电源上电。
4. 松开 SW2 500 ms，确认 OLED 显示安全状态且已出现 `A`。
5. 按 SW4，确认进入 `E-STOP`；复位后重新完成解锁。
6. 接通电机主电源，短按住 SW2 约 0.5 s，确认松手立即停转。
7. 再按住 SW2 约 2 s，观察两轮是否同向、编码器是否都为正，并记录 `dL`、`dR`。
8. 停止后按 SW3 切换后退，重复短时测试，确认两侧计数都为负。
9. 运行中按 SW4，确认两轮立即停止且不会自动恢复。
10. 连续做 10 次短时启动；没有误报、掉线或异常振动后，才进入双轮速度闭环调试。

如果 PWM 600 时电机完全不转，不要直接大幅提高 PWM。先检查电机主电源、共地、PB16/STBY、驱动方向线和编码器供电；接线正确后再按 100 为一级逐步增加测试 PWM。

## 通过标准

- 上电或复位不会自动转动。
- SW2 松开和 SW4 按下都能让两轮立即停止。
- 左右轮同向，前进编码器均为正、后退均为负。
- 两边都持续有编码器反馈，没有断线故障。
- 相同 PWM 下左右计数差异不会持续超过 50%。
- 10 次短时启动均无误动作。

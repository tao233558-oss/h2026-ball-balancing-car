# 硬件接线与操作

## 1. STM32F407、ST-Link

主控：立创·梁山派·天空星 STM32F407VET6。

ST-Link 使用 SWD：

| ST-Link | STM32 开发板 |
|---|---|
| SWDIO | 板载 SWDIO |
| SWCLK | 板载 SWCLK |
| GND | GND |
| 3.3V/VREF | 3V3，仅作参考电平；主板已有供电时不要再用 ST-Link 给大功率负载供电 |

所有模块必须共地。电机、步进驱动的功率电源不能从 STM32 3.3V 获取。

## 2. 四路数字红外循迹

模块按车头方向从车身左到右排列：S1、S2、S3、S4。

| 模块 | STM32 | 实测逻辑 |
|---|---|---|
| S1 | PB1 | 白 0，黑 1 |
| S2 | PB0 | 白 0，黑 1 |
| S3 | PC5 | 白 0，黑 1 |
| S4 | PC4 | 白 0，黑 1 |
| VCC | 3V3 | 不接 5V，避免输出超过 MCU 电平 |
| GND | GND | 必须共地 |

实测单路压线：S1=`1000`、S2=`0100`、S3=`0010`、S4=`0001`。模块高度曾约 9 mm，快速移动时有跳变；机械安装高度、平行度和遮光必须固定。

注意：早期八路模拟模块中 D1 的车身方向与当前四路模块不同，不要混用旧结论。

## 3. TB6612 与直流电机

| TB6612 | STM32 | 功能 |
|---|---|---|
| PWMA | PE13 / TIM1_CH3 | 左电机 PWM |
| AIN1 | PD0 | 左电机方向 |
| AIN2 | PD1 | 左电机方向 |
| PWMB | PE14 / TIM1_CH4 | 右电机 PWM |
| BIN1 | PD2 | 右电机方向 |
| BIN2 | PD3 | 右电机方向 |
| STBY | PD4 | 驱动使能 |
| VCC | 3V3 | 逻辑电源 |
| VM | 电机电源 | 按电机/驱动规格供电 |
| GND | 公共 GND | 必须与 STM32 共地 |

方向已经验证：左轮向前时 L 编码器增加，右轮向前时 R 编码器增加。

## 4. 编码器

| 编码器 | STM32 | 定时器 |
|---|---|---|
| 左 A | PB4 | TIM3_CH1 |
| 左 B | PB5 | TIM3_CH2 |
| 右 A | PB6 | TIM4_CH1 |
| 右 B | PB7 | TIM4_CH2 |
| VCC/GND | 按模块规格/GND | 与 STM32 共地 |

历史架空测试：正转约 L=4049、R=4001；反转复测约 L=-4088、R=-3884。实际值只用于确认方向和量级，不是永久标定值。

## 5. OLED

| OLED | STM32 |
|---|---|
| SCL | PB10 |
| SDA | PB11 |
| VCC | 3V3 |
| GND | GND |

OLED 为软件 I²C。控制循环中不要每次都整屏刷新，建议 200～250 ms 刷新一次。

## 6. 按键

按键按下接地，MCU 内部上拉：

| 按键 | STM32 | 当前 V17 用途 |
|---|---|---|
| SW1 | PE7 | LEVEL 状态车尾上升；READY 且视觉有效时启动 Q3 |
| SW2 | PE8 | LEVEL 状态车尾下降 |
| SW3 | PE9 | 确认水平/置零；视觉丢失恢复时按提示继续 |
| SW4 | PE10 | 急停 |

循迹版本中的按键含义以该源码 OLED 提示为准，切换主程序后不要沿用 V17 的按键含义。

## 7. 单路步进驱动和摆杆

| 步进驱动 | STM32 | 说明 |
|---|---|---|
| STEP/PWM | PA6 | 脉冲 |
| DIR | PA7 | 方向 |
| SLP | PA5 | 睡眠/使能 |
| RST | PA4 | 复位，程序主动控制 |
| DCY | 不接 | 当前驱动与代码未使用 |
| 控制 GND | STM32 GND | 必须共地 |
| 功率输入 | 独立电源 | 按驱动和电机规格 |

步进电机接驱动的 A+/A-/B+/B-，先用万用表找出两组线圈，不能按线色猜。

已验证符号：

- 正步数：车尾上升。
- 车尾上升：小球向负 x/左侧加速。
- 约 258 step/°。
- 机械启动死区约正向 288 step、反向 253 step，随负载和机构摩擦变化。
- 当前软件软限位约 ±420 step。机械无硬限位开关，首次测试必须有人随时按 SW4 并观察机构。

## 8. K230 视觉串口

| K230 | STM32 | 参数 |
|---|---|---|
| 40Pin 第 11 脚 GPIO5/TX | PA3 / USART2_RX | 9600, 8N1, 3.3V TTL |
| GND | GND | 必须共地 |

当前 ASCII 帧：

```text
[x,y]\r\n
```

STM32 主要使用 x。接收使用 USART2 RX 中断，不使用主循环轮询等待。K230 三点像素标定：左端 x=37、中心 x=351、右端 x=658，对应约 -125/0/+125 mm。拿走小球后应判无效，STM32 视觉超时为 300 ms。

K230 Type-C：烧写、调试、图传或供电时按实际方案接；正式运行若已由车载稳定电源供电并从 TF 卡自启，不要求一直连电脑。避免电脑 USB 与车载电源形成不可靠地线回路。

## 9. 临时 JY61P/MPU6050

JY61P 曾用于测摆杆倾角和机械标定，代码中有 UART4 RX 驱动（PC11）。正式比赛不得把它装在水管上作为钢球位置检测；赛题明确要求凹槽内钢球位置检测必须使用摄像头。

## 10. 上电和测试顺序

1. 架空驱动轮，钢球先取下或用手防护，步进机构置中。
2. 只给 STM32 和逻辑模块上电，确认 OLED 版本号。
3. 确认急停 SW4 有效。
4. 再接电机/步进功率电源。
5. 平衡测试先完成 LEVEL：SW1/SW2 调水平，SW3 确认。
6. 检查 K230 坐标：球向右 x 增加，球向左 x 减少，拿走球后视觉应超时。
7. 最后把球放到中心，按程序提示启动。

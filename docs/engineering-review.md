# 工程复盘：问题、判断与改进

## 四路红外为什么既会冲弯又会摆动

赛时经历过“直线稳定、入弯外冲”“加大转向后直线摆动”“外侧单点压线突然加速”“速度切换造成顿挫”。这些现象不能统一归因于模块不灵敏。

固定压线时，电机停止和转动均读到0110，快速横移赛道时才跳变，模块曾距地约9 mm。这支持继续检查检测几何、阈值、采样时间与车速，而不是仅凭运动中的跳变判定电磁干扰。

改进采用离散状态分类：0110、0100、0010允许直线目标速度，1000/0001优先转向降速；丢线短时沿上一次方向搜索，超时停车。对固定赛道再按编码器累计里程提前减速。所有目标经速度斜坡，再进入两轮速度PI，减小速度突变。

最终人工记录约40 s完成一圈，仍未达到20 s。固定里程策略依赖起点和轮径，后续应增加前视距离、固定安装与曝光/遮光条件，并测量实际轮速和过弯轨迹。

## P=T为什么不能说明滚球已稳定

P是已发出的步数，T是目标命令。传动打滑、步进失步、回差和卡滞不会被软件计数发现；即使P=T，管道倾角仍可能未到位。球停住还可能来自管球接触阻力或过早撤去起动补偿。

当前控制用球位置误差与速度产生步进目标，并设置定向起动补偿。V17保留作为功能回退基线；后续大幅加增益的版本出现了更大停留偏差，因此未将它们标成最终版本。

合理后续路径是球位置外环产生目标管道倾角，角度/齿条位移内环控制执行器，同时加可重复回零结构。真实比赛方案须服从题目传感器限制，临时标定传感器与最终传感方案分开说明。

## 串口收到了新帧，图像就一定更新了吗

V17帧为[x,y]，无序号和图像时间戳，STM32只能判断串口合法帧的接收时间。若K230重复旧坐标，V可能长期为0却不触发收帧超时。改进协议可加入帧序号、识别有效位和图像采集时间，同时对不可能的坐标跃变做拒收。

## 后续验收

每个候选版本至少记录5次完整试验：初始位置、目标、到达时间、过冲、最终误差、视觉帧龄、限位与故障状态。统计样本数、最大误差、平均误差和成功率。构建通过、烧录通过、仿真通过与实车达标分别记录。

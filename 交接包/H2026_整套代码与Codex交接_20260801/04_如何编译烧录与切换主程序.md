# 如何编译、烧录与切换主程序

## 1. Keil 工程入口

```text
STM32F407完整Keil工程\project\MDK(V5)\Project.uvprojx
```

本机 Keil：

```text
E:\Downloads\Keil5\UV4\UV4.exe
```

## 2. 先验证 V17 基线

不要修改任何文件，先用 PowerShell：

```powershell
$env:ARM_TOOL_VARIANT='mdk_lite'
Get-FileHash -Algorithm SHA256 '.\STM32F407完整Keil工程\app\main.c'
& 'E:\Downloads\Keil5\UV4\UV4.exe' -b '.\STM32F407完整Keil工程\project\MDK(V5)\Project.uvprojx' -j0
```

预期：0 error、0 warning。若 Keil GUI 打开工程，点击 Rebuild 也可。

## 3. 用 ST-Link 烧录

### Keil GUI

1. ST-Link 接 SWDIO、SWCLK、GND、VREF/3V3。
2. 主板上电，电机和步进机构先保持安全。
3. 打开 `Project.uvprojx`。
4. Options for Target → Debug 选择 ST-Link Debugger。
5. Utilities 确认使用调试器下载。
6. 点击 Download。
7. 查看 Build Output：必须出现 Erase、Programming、Verify 成功。
8. 复位开发板，核对 OLED 首行版本号。

### 直接烧 V17 HEX

若只需恢复已验证固件，使用 `当前V17固件/Project_V17.hex`，用 Keil 或 STM32CubeProgrammer 通过 ST-Link 烧录。烧录后 OLED 应显示 V17 相关页面。

## 4. 切换为循迹主程序

当前工程同一时间只编译 `app/main.c`。切换过程一定要保留原文件：

1. 复制当前 `app/main.c` 为 `app/main_balance_v17_before_switch.c.saved`。
2. 从以下文件中选一个：
   - 通用循迹：`app/main_stage41_4ch_line_v20_flowing_curve.c.saved`
   - 固定路线：`app/main_stage49_v1_fixed_route.c.saved`
3. 把选中的文件内容复制到 `app/main.c`。
4. 修改 OLED 版本字符串，确保与之前固件不同。
5. Rebuild，确认 0 error/0 warning。
6. 架空车轮后烧录，先检查传感器位序、按键和电机方向，再落地。

不要把 `.saved` 文件扩展名直接加入 Keil 编译组，否则可能出现多个 `main`。

## 5. 切回平衡 V17

最可靠方式：

1. 将 `当前V17固件/main_V17_当前已烧录.c` 复制覆盖 `STM32F407完整Keil工程/app/main.c`。
2. 核对 SHA256。
3. Rebuild。
4. 烧录并核对 OLED V17。

或者直接烧 `当前V17固件/Project_V17.hex`，但这只恢复芯片固件，不会自动恢复工程源文件；因此源文件仍应核对。

## 6. 新版本保存规范

每次修改后保存：

```text
app/main_v23_简短说明.c.saved
project/MDK(V5)/stage79_v23_简短说明_build.log
project/MDK(V5)/stage79_v23_简短说明_flash.log
firmware/Project_v23.hex
test/stage79_v23_实测.md
```

版本号应同时出现在：源码头注释、OLED 首行、日志文件名、HEX 文件名、测试记录中。

## 7. 合并循迹和平衡的正确方式

不要把两个 `while(1)` 直接拼接。建议统一为非阻塞状态机：

```text
BOOT
  -> SAFE/SELF_TEST
  -> MODE_SELECT
  -> TRACK_ONLY
  -> Q3_STATIC
  -> TRACK_CENTER_BALANCE
  -> TRACK_ASSIGNED_BALANCE
  -> STOP/RESULT
  -> EMERGENCY
```

调度建议：

- 1 ms：系统节拍、按键消抖。
- 10 ms：视觉更新、平衡控制、步进目标更新。
- 10～20 ms：编码器测速、循迹控制、电机 PI。
- 200～250 ms：OLED。
- 串口和 USB：中断/DMA 或环形缓冲，主循环不得阻塞等数据。

## 8. 烧录后每次都要做的检查

1. OLED 版本号是否正确。
2. SW4 是否能立即急停。
3. 车轮架空时正转编码器是否都增加。
4. S1～S4 位序是否为左到右且黑=1。
5. K230 坐标左右符号是否正确。
6. SW1 使车尾上升、SW2 使车尾下降。
7. 步进软件位置 POS 是否与运动方向一致。
8. 视觉拔线或拿走球后，系统是否在 300 ms 左右进入安全状态。

## 9. 禁止事项

- 禁止不留副本直接覆盖 V17。
- 禁止在车轮落地、摆杆接近机械极限时首次测试新固件。
- 禁止用旧 OLED 界面判断“烧录成功”；必须使用新版本字符串。
- 禁止把旧八路模拟循迹的 D1 方向套到当前四路数字模块。
- 禁止以球“停住”代替“到达目标坐标”。

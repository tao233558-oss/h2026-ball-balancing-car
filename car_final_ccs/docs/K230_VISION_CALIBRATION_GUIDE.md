# K230 靶面与光斑标定指南

## 当前软件状态

K230 脚本已经统一使用 A4 纸物理坐标：

- 黑色外框提供四个透视角点。
- 红色同心圆像素用于修正靶心；红色识别失败或偏离过大时，自动回退到 A4 投影中心。
- E6 的目标点由 A4 平面上的半径 60 mm 圆投影到摄像头画面，不再使用四角平均近似。
- K230 上电默认处于 `STOP`，且 `AUTO_LASER_ENABLE = False`。

离线几何和协议已经通过，但以下参数不能靠电脑合成图确定：

```python
CAMERA_ROI
BLACK_THRESHOLD
RED_TARGET_THRESHOLDS
LASER_THRESHOLDS
```

## 第一次标定前

1. 云台、电机和激光控制线先不接，只给庐山派、摄像头和显示供电。
2. 把 A4 靶纸按实际比赛距离和角度固定，避免手持晃动。
3. 在 CanMV IDE 中同时上传 `main.py`、`aim_protocol.py`、`target_geometry.py`。
4. 保持 `AUTO_LASER_ENABLE = False`，不要为了调色直接打开自动激光。
5. 固定摄像头曝光和白平衡后再采颜色；自动曝光持续变化会让同一阈值失效。

## 分四步标定

### 1. 画面与 ROI

- 确认整张 A4 靶纸始终处于 `CAMERA_ROI` 内。
- 小车运动或云台转动时，四个黑框角不能离开 ROI。
- ROI 不宜过大，否则帧率下降；也不能紧贴靶框，应留出抖动余量。

### 2. 黑色外框

- 先只观察绿色四边形轮廓。
- 正视、左右斜拍、上下斜拍和远近变化都应只选中最大 A4 外框。
- 误检背景黑物体时，收紧 `BLACK_THRESHOLD`、缩小 ROI，或提高 `find_rects` 的 `threshold`。

### 3. 红色靶心

- 观察红色十字是否稳定落在同心圆中心。
- 调整 `RED_TARGET_THRESHOLDS`，让红色圆环能被识别，同时排除背景红物体。
- 软件设有偏移保护：红色质心离 A4 投影中心超过靶面短边的 18% 时会被拒绝，并使用几何中心。

### 4. 紫色/405 nm 光斑

- 必须按实际曝光、实际靶纸和实际环境光重新采样 `LASER_THRESHOLDS`。
- 先用最低安全功率、固定靶面、避免镜面反射，并佩戴对应波长的防护措施。
- 光斑应显示为紫色圆圈；没有光斑时不得出现 `SPOT_VALID`。
- 调整阈值时同时检查白纸高光、红色圆环和环境紫色物体不会被误识别。

## 验收记录

每一种距离和角度至少记录：

| 项目 | 建议最低要求 |
|---|---|
| A4 外框连续识别 | 100 帧中不少于 95 帧 |
| 无靶误识别 | 100 帧中不超过 1 帧 |
| 有光斑识别 | 100 帧中不少于 95 帧 |
| 无光斑误识别 | 100 帧中不超过 1 帧 |
| 静止靶心抖动 | 峰峰值先控制在约 4 像素内 |
| UART CRC 错误 | 连续运行时保持为 0 |

标定完成后保存一组原始图像、当前阈值、曝光参数、距离、角度和环境光条件。不要只记录“能识别”，否则换场地后无法判断是哪项参数发生了变化。

## 仍未验证的部分

当前没有真实硬件和真实 405 nm 光斑数据，因此相机 API 运行、帧率、曝光、LAB 阈值、光斑安全性和实物误差均为 `NOT_RUN`。离线测试通过不代表这些项目已经验收。

# 求职展示与面试讲解

## 简历项目描述参考

> 车载平衡滚球运动控制系统｜嵌入式控制开发｜STM32F407 / C / Keil
>
> 负责差速底盘与单步进执行器的嵌入式控制开发，完成定时器PWM、双轮编码器、速度PI、四路红外循迹、UART中断接收及OLED按键交互；与视觉同学协作对接K230钢球坐标，通过三点分段标定实现毫米坐标转换及滚球序列状态机。实车实现约40 s循迹一圈，保留完整构建日志、版本回退与问题复盘。

这段描述只覆盖已有记录，不包含获奖、20 s达标、行驶中滚球稳定等尚未证实的成果。根据自己的真实参与和能够解释的细节再放入简历。

## 三分钟讲解顺序

1. 展示实物照片，说明目标：差速小车循迹，单步进改变车载管道倾角。
2. 说明分工：本人主控和非视觉模块，队友视觉检测、训练和图传。
3. 打开四路循迹代码，解释中心单点、外侧边缘、丢线三类状态及轮速PI。
4. 打开视觉中断、环形缓冲和解析器，解释如何避免主循环等待串口。
5. 展示V17状态机与日志，说明为什么保留回退基线以及尚未达标的根因。

## 值得准备的问题

| 面试问题 | 可以展示的证据 |
|---|---|
| 为什么不同通道压线要采用不同速度？ | 固定路线主程序及工程复盘 |
| PWM、编码器采样、控制周期怎样配合？ | bsp/motor、bsp/encoder、speed_pi与20 ms循迹循环 |
| 串口粘包、拆包、溢出、失联怎样处理？ | bsp/vision_uart及protocol的中断/环形缓冲/状态解析 |

| 从MSPM0迁移到STM32做了哪些工作？ | 两套板级工程、引脚映射、外设与驱动差异 |

## 贡献边界

STM32与MSPM0控制代码包含原始工程复用、厂商库、赛时修改及工具辅助开发。面试展示重点是本人实际接线、调试、集成、观察和理解的内容。K230模型训练和图传由队友负责；不得把厂商库、参考工程或队友代码描述为个人从零独立完成。

# 循迹外环＋双轮速度 PI 内环

## 当前状态

级联控制已经通过 `user/e2025_drive_adapter.c` 接到 E2025 主程序，但由独立开关保护，默认不参与电机输出：

```c
#define E2025_OFFLINE_SIMULATION 1
#define E2025_ENABLE_CASCADE_TRACKING 0
```

这表示代码路径已经能够编译和离线验证，不表示目标速度与 PI 参数已经完成实车标定。默认固件仍将 PB16/STBY 拉低，左右 PWM 为 0。

## 两层控制结构

1. 循迹外环每 10 ms 读取八路传感器，根据黑线位置生成左右轮目标编码器计数。
2. 适配层累计 10 个编码器增量，形成 100 ms 实际计数。
3. 左右速度 PI 每 100 ms 独立调整 PWM，以追踪外环给出的目标。

八路传感器内部统一规定 `bit0`～`bit7` 对应 D1～D8，`bit=1` 表示压到黑线。

## 当前占位目标

| 状态 | 左目标 | 右目标 | 动作 |
|---|---:|---:|---|
| D4/D5 居中 | 10 | 10 | 直行 |
| 黑线偏左 | 降低 | 提高 | 向左修正 |
| 黑线偏右 | 提高 | 降低 | 向右修正 |
| 向左搜索丢线 | 0 | 7 | 左转找线 |
| 向右搜索丢线 | 7 | 0 | 右转找线 |
| D1/D2 直角 | 0 | 10 | 左轮停、右轮转 |
| D7/D8 直角 | 10 | 0 | 右轮停、左轮转 |

普通循迹的目标限制在 7～13 计数/100 ms。所有数值都是离线占位值，不是实车速度结论。

## 编码器保护

保护逻辑同时查看实际计数和目标计数：

- 目标大于 0 的车轮必须出现正确方向的反馈；
- 目标为 0 的车轮允许停止，不会误报掉线；
- 两轮目标不同时，按目标比例比较实际计数；
- 无反馈、单侧反馈丢失、方向错误和持续速度偏差都会锁存故障；
- 故障发生当周期关闭 PB16/STBY，并保持到芯片复位。

某一轮目标从正数变成 0 时，该轮 PWM 在当前 10 ms 周期立即清零，不等待下一个 100 ms PI 周期。

```powershell
python offline_tools\track_cascade_sim.py

```

第一项回放外环、PI、电机模型和目标感知保护；第二项验证主程序适配层的 10/100 ms 时序、单轮停车、无反馈锁存、SW4 急停和默认功能门控。

## 实车启用前必须测量

1. PWM 600 时左右编码器每 100 ms 的平均计数与波动范围。
2. 左右轮前进时计数符号是否都为正。
3. 目标 7、10、13 是否都位于电机可稳定运行范围。
4. PI 参数能否在车轮悬空时平稳收敛且没有持续振荡。
5. 低速落地时普通弯道和直角弯所需的实际目标差。

完成这些测量前，不要烧录并运行闭环开启配置。

# 完整归档说明

本仓库将赛时工作区中的完整项目代码、历史版本、厂商依赖和交接资料整理上传。主代码目录保留原有相对路径，便于工程、脚本与历史日志相互对照。

- `archive/source-manifest.csv`：入库文件、原工作区相对位置、字节数和SHA256；复制时逐文件校验。
- `archive/excluded-files.csv`：未入代码仓库的工具安装包、IDE缓存、构建中间文件等，逐项列明原因。
- `archive/publication-changes.csv`：公开前替换的8处无线AP密码及移出的2个SDK示例签名私钥，同时移除原工程ZIP中的对应密钥副本。AP密码统一改为部署占位值；MCUboot示例签名密钥不属于项目业务代码，原始文件保留在本地。
- `交接包/H2026_整套代码与Codex交接_20260801/`：完整赛时项目快照，包括历史主程序、现有K230资料、V17固件、接线与实测记录。
- `咸鱼24电赛h/`：复用来源、SDK源码和原始示例；其内容不应全部归为个人原创。
- `docs/reports/`：原始报告与生成脚本归档，报告中的旧技术表述以`current-state.md`勘误为准。

IDE可执行文件、CanMV/OpenMV安装目录、系统固件镜像、Python/NumPy等工具依赖缓存不作为项目源码上传。无关的早期数字识别数据集未收入。编译中间文件可由Keil/CCS重新生成；已知V17 HEX/AXF作为回退证据保留。

重复目录是赛时交接快照；其存在是为了保留工程状态。`source-manifest.csv`记录整理时的原始副本哈希；如公开时替换局部网络密码，会在单独的公开处理记录中列出，仓库原始代码不因此被静默改写。
